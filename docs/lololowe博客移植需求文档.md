# lololowe 博客深度分析 + 移植需求文档
> 文档版本：v1.0　|　编写日期：2026-08-17　|　分析对象：https://blog.lololowe.com/
> 用途：分析目标站点的全部元素，作为「web3-blog 项目」移植实施的需求依据
> 优先级定义：**P0**＝核心可用的博客体验　**P1**＝氛围/互动增强　**P2**＝外围增值

---

## 0. 站点技术栈识别（分析结论）

| 项目 | 识别结果 | 证据 |
|---|---|---|
| 博客框架 | **Hexo** + **anzhiyu（安知鱼）主题**（butterfly 系衍生） | `PAGE_NAME`、`anzhiyu.scrollToDest()`、`loading3.gif` 占位、`toRandomPost`、快捷键面板、中控台等均为 anzhiyu 主题特征 |
| 评论系统 | **Twikoo** | 「匿名评论」「隐私政策」「✅ 你无需删除空行，直接评论以获取最佳展示效果」为 twikoo 特征文案；支持评论弹幕 |
| 音乐播放器 | **APlayer + Meting**（网易云源） | `/music/?id=652135520&server=netease` 为 MetingJS 标准参数 |
| 搜索 | 本地搜索（hexo-generator-searchdb） | 键盘快捷键 shift+S 打开站内搜索 |
| 统计 | 不蒜子 / hexo 内置计数 | 文章页阅读时长、评论数、网站资讯面板 |
| AI 摘要 | 第三方 AI 摘要服务（TLDR GPT 类） | 文章页顶部「AI-摘要 TLDR GPT，AI初始化中」 |
| 首页结构 | 三栏式：左（个人卡+标签云+归档）中（文章流）右（最近更新+统计） | 抓取 DOM 结构确认 |
| 站点性质 | 网络安全/网络运维技术博客 + 自建子站群 | 分类：计算机网络/网络安全/网络设备配置/编程/渗透/靶场 |

### 结论
目标站是**内容为王的个人技术博客**：核心价值 = 文章流体验（卡片信息密度、阅读动线、目录、相关推荐）+ 全站氛围组件（快捷键、弹幕、音乐、中控台、右键增强、打赏）。移植时应把有限资源放在 **P0 博客内容链路**，氛围组件按 P1/P2 分批。

### 1.1 页面骨架（所有页面通用）
```
┌────────────────────────────────────────────────────────┐

├────────────────────────────────────────────────────────┤

│ 社交链接       │                    │ 最新评论              │

│ 归档列表       │                    │ 标签云/网站资讯        │

        快捷键面板 · 右键增强菜单 · 通知/公告 · 打赏按钮
```

## 2. 首页文章流（P0 核心）

### 2.1 文章卡片（列表项）
| 元素 | 说明 |
|---|---|
| 封面图 | 卡片顶部，懒加载（loading3 占位），宽高比 16:9 左右 |
| 分类徽标 | 卡片左上角，主分类名，点击直达分类页 |
| 标题 | 加粗大字号，hover 变色 |
| 摘要 | 首段/截断摘要，2-3 行截断 |
| 元信息行 | 发表于日期 · 标签（1~3 个，点击直达标签页）· 未读红点标记 |
| 阅读数据 | 字数统计、预计阅读时长（分钟）、评论数（可选） |

### 2.2 列表行为
| # | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| A1 | 首页文章流：真实数据，按发布时间倒序，分页（页码+下一页） | 无 mock；翻页正常；URL 反映页码 | P0 |
| A2 | 卡片信息完整（封面/分类/标题/摘要/日期/标签） | 逐项核对展示 | P0 |
| A3 | 「未读」标记：本地 localStorage 记录已读文章 id，未读显示红点 | 点开文章后回到列表红点消失 | P1 |
| A4 | 「随便逛逛」：随机跳转到任意一篇文章 | 每次点击目标不同，无重复死链 | P1 |
| A5 | 置顶文章（可选）：`is_top` 的文章置顶显示并带置顶徽标 | 置顶条目在前 | P2 |

## 4. 全站氛围组件（P1 重点，P2 可选）

### 4.1 快捷键系统（P1）
| 按键 | 功能 |
|---|---|
| Shift+S | 站内搜索 |
| Shift+D | 深色/浅色切换 |
| Shift+R | 随机访问 |
| Shift+H | 返回首页 |
| Shift+M | 播放/暂停音乐 |
| Shift+A | 开/关中控台 |
| Shift+L | 友链页 |
| Shift+P | 关于本站 |

### 4.2 右键菜单增强（P1）

### 4.3 中控台（P1）
- 浮动控制面板：站点统计（文章/标签/分类数）、主题切换、音乐控制、快捷入口、显示当前页面 URL 的"小板报/距离"装饰

## 9. 与现有项目差距对照（web3-blog）

| 目标站元素 | 本项目现状 | 结论 |
|---|---|---|
| 三栏布局 + 多级菜单 | 已有 Web3Layout（顶栏+页脚），无侧栏三栏 | 需新增布局能力 |
| 文章流卡片 | blog-service 已有 article 表 + list/hot/{id}/like 接口 | 补 摘要/字数/封面/分页 字段与接口 |
| 文章详情 | 已有详情接口（含 content） | 补 上一篇/下一篇、相关推荐、TOC 数据 |
| 评论区 | forum-service 有 comment 表（论坛用） | 扩展为文章评论或复用 |
| 音乐播放器 | `views/music/` 有播放器雏形（无后端） | 补网易云歌单后端代理（本项目已有 gateway，可走 /v1 反代或独立接口） |
| 友链 | `views/link/` 占位页 | 建 friend_link 表 + CRUD + 管理端 |
| 留言板 | `views/comments/` 本地 mock 示例 | 接真实接口 |
| 工具库 | `views/tools/` 已有 ToolPage + 3 处请求 | 补分类与卡片形态 |
| 相册 | `views/album/` 占位 | 补图床接口（media-service 已有） |
| 快捷键/中控台/右键增强 | 无 | 全新建（纯前端） |
| 深色/浅色切换 | 主题已支持暗色 | 补切换开关与持久化 |
| 归档/分类/标签页 | 无独立页 | 建页 + 接口 |
| 打赏/分享/版权声明 | 无 | 纯前端组件 |
| 统计页 charts | admin 有 dashboard | 前台统计页需另建 |
